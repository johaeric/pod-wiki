# Suzy Bolt's recovery program

A multi-component online program for LC recovery, built and run by [[suzy-bolt]] with co-teacher [[ross-cooper]]. Membership-based; 9+ live classes a week ranging from chair yoga (level zero, in-bed-and-watching counts) up to gentle Pilates and beginner weights, plus weekly group Q&A.

Branding/name varies in episodes ("the program", "3-2-1", "Suzy Bolt 360"); update the slug if/when she names it canonically.

## Core elements

- **Levelled progression** — bed-watching → chair-yoga → standing → light resistance.
- **Daily community** — live attendance, witnessed by name; explicit anti-loneliness design.
- **Curated Facebook group** — moderated to skew forward-looking (not symptom-trauma).
- **Buddy pairings** for layered peer support.
- **Embedded interviews** with clinicians (e.g. [[boon-lim]], [[melanie-dani]]) on YouTube.
