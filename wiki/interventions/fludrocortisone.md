# Fludrocortisone (Florinef)

Synthetic mineralocorticoid. In POTS / autonomic dysfunction: promotes renal sodium reabsorption → expands plasma volume → reduces orthostatic intolerance.

**Eric is on florinef** — see project `CLAUDE.md`. Pages are unusually load-bearing.

> Cross-ref: see `ercipedia/wiki/interventions/fludrocortisone.md` for trial evidence picture.

## Practical considerations (per Boon Lim #40)

- Standard caveat: "weak steroid" — Lim recommends staying on for ≤1 year if possible, then trying head-of-bed elevation as a non-drug volume-expansion alternative (acts like endogenous fludrocortisone).
- Non-drug stand-ins (Lim's order): cold water + electrolytes pre-rise → salt loading → compression → isometric exercises → bed-head elevation → midodrine → fludrocortisone.
