# Gua Sha

A pressing/scraping technique from East Asian medicine. A smooth-edged tool (traditionally stone; Elizabeth So uses a jar lid in clinic) is dragged along the skin with oil. Functions like cupping but uses pressure-and-glide rather than suction. Brings "biological debris" (purple/red splotches resembling cup-marks) to the skin surface where the body can break down and excrete it.

## Why it's used in LC specifically (per ep #124)

LC's chronic inflammation + circulation impairment is hypothesised to leave debris jammed in the bloodstream and accessory breathing muscles, especially in the lungs. Blockages → more congestion → vicious cycle. Gua sha helps the body release the debris pile-up so the ecosystem can rebalance.

## Diagnostic value

If gua sha brings up a lot of marks: blood-stasis is present and was load-bearing. If nothing surfaces: blood-stasis was not the issue — useful information either way. So treats it as both treatment and a low-cost differential probe.
