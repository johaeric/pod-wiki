# Glenn Chan's Recovery (vaccine-injury, mostly recovered, Python-driven research approach)

Ontario Canada programmer. Vaccine-injured June 2022. Severe insomnia + brain fog + can't-walk-and-talk + can't-program. **~95% recovered** via:

1. **Ivermectin** ("the eye drug" — he avoids saying the name on YouTube for censorship reasons) — **single biggest intervention** at ~month 8.
2. **Black seed oil** — added later, compounding gains.

His broader contribution to the LC / ME-CFS / vaccine-injury community: built **sickandabandoned.org**, a patient-led survey + Python data analysis effort to identify which treatments help vs. harm. Key findings:
- HBOT, fasting (>48hr wet), antimicrobial supplements/drugs ranked promising
- SSRIs, gabapentin, antibiotics ranked bottom (consistent worsening)
- Even working treatments (HBOT) can permanently set some patients back
- **Discontinue worsening treatments** — don't trust herxheimer-as-progress framing

## Wiki position

Substantial-not-full recovery. Vaccine-injury cohort. **First data-analysis-driven recovery story on the corpus** — useful as exploratory map of treatment-response patterns. Small-N caveat throughout.
